# Ambient Drone Generator

A minimal, interactive **ambient drone instrument** built for the browser.

This project turns a full-screen canvas into a 2D sound space where **movement creates mood**.  
There are no knobs, presets, or menus — just touch, motion, and sound.

---

## 🎛 What It Does

- **Click / touch and move** on the canvas to generate sound
- **X-axis** → pitch (snapped to a musical scale)
- **Y-axis** → brightness / timbre
- **Movement speed** → energy and shimmer
- Slow evolution even when still

Designed to feel less like a synth and more like a *space you interact with*.

---

## 🧠 Design Philosophy

- Minimal UI  
- Generative, not loop-based  
- Always musically “safe” to explore  
- Long timescales → calm, ambient behavior  

Inspired by:
- Ambient music systems
- XY pad controllers
- Generative sound art
- Brian Eno–style “systems over songs”

---

## 🛠 Technologies Used

- **HTML5 Canvas** — interactive visual surface
- **Web Audio API** — real-time audio synthesis
- **Pointer Events API** — unified mouse + touch input
- **Vanilla JavaScript** — no frameworks, no dependencies
- **CSS** — subtle glassmorphism + dark ambient styling

No external libraries. No audio files. Everything is generated live in the browser.
